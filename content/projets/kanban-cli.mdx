## Le projet

Un tableau kanban qui vit dans le terminal : les cartes sont stockées localement dans SQLite et synchronisées avec les issues GitHub du dépôt courant.

```bash
kanban add "Corriger l'export CSV" --label bug
kanban move 42 done
```

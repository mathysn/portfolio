## Le contexte

Les techniciens recevaient leurs interventions par SMS et remontaient les comptes rendus le soir, depuis le dépôt. Relais centralise la messagerie, les fiches d'intervention et les photos dans une seule application mobile.

### Contraintes techniques

- Zones blanches fréquentes : tout doit fonctionner hors ligne
- Synchronisation sans conflit entre le terrain et le back-office
- Notifications fiables sur Android d'entrée de gamme

## Architecture

L'application React Native stocke les messages dans SQLite et rejoue une file d'opérations à la reconnexion. Côté serveur, un cluster Node.js diffuse les événements via WebSocket, avec Redis comme bus de publication.

```ts title="sync/queue.ts"
export async function flush(queue: Operation[]) {
  for (const op of queue) {
    await api.apply(op); // idempotent : rejouer une opération est sans risque
  }
}
```

<Callout type="info" title="Bon à savoir">Chaque opération porte un identifiant unique : le serveur ignore les doublons.</Callout>
